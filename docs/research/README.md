# Private Research Workspace

Detailed Devflow research notes, reports, paper drafts, related-work maps, and
experiment fixtures are maintained in a private repository:

- `Sungblab/devflow-native-research`

The public `devflow-native` repository keeps the product implementation,
public product documentation, and reusable workflow contracts. Active research
claims, professor-facing reports, pilot fixtures, scoring scripts, and
non-public analysis should be kept out of this public repository.
