# Devflow Native v0.1.3

This is a positioning and release-automation pass for the v0.1 foundation line.

## What Changed

- Reframed the README around the concrete user pain: stop AI coding agents from
  claiming "done" without repo-local evidence.
- Added a comparison table that separates Devflow Native from Codex, Claude
  Code, host hooks, Superpowers, and TaskMaster-style task tools.
- Replaced public-facing MVP wording with v0.1 foundation release language.
- Added tag-driven GitHub Actions release automation for npm publishing and
  GitHub Release creation.
- Documented npm Trusted Publisher setup for OIDC-based publishing without a
  long-lived `NPM_TOKEN`.

## Verification

Release candidates should pass:

```powershell
npm run publish:check
```

The release workflow runs the same check before publishing.

## Maintainer Setup Required

For fully automated npm publishing, configure the npm Trusted Publisher for the
`devflow-native` package:

```text
Repository owner: Sungblab
Repository name: devflow-native
Workflow file: release.yml
Environment name: npm-publish
```
