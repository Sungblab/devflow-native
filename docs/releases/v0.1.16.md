# Devflow Native v0.1.16

This release adds the preset-based `devflow init` bootstrap surface for new
repositories.

## What Changed

- Added `devflow init --preset ...` support for `standard`, `solo-product`,
  `research`, and `content-site`.
- Added generated `.devflow/config.json`, `AGENTS.md`, GitHub Actions, and
  repo-local `plugins/devflow/*` harness files.
- Added automatic gate inference from package scripts such as lint, test,
  build, docs, links, and bench.
- Added review policy generation, including `review.required=true` for
  `solo-product`.
- Added `devflow.init` to the MCP surface.
- Added repo-local init skill and command wrappers so agent hosts can call the
  Devflow CLI rather than owning bootstrap policy themselves.

## Upgrade Notes

Existing repositories are not modified automatically. To preview a bootstrap
plan in a new or existing repository, run:

```powershell
devflow init --preset solo-product --targets codex,claude --ci github --review required --json
```

Apply the generated files only after reviewing the plan:

```powershell
devflow init --preset solo-product --targets codex,claude --ci github --review required --confirm --json
```

## Verification

```powershell
npm test
npm run docs:check
node packages/cli/src/index.js health --json
node packages/cli/src/index.js harness health --targets codex,claude --json
```
