# Devflow Native v0.1.4

This patch release makes the release automation re-runnable after a package
version has already been published.

## What Changed

- Updated the npm publish check so package contents are always validated with
  `npm pack --dry-run`.
- Kept `npm publish --dry-run` for unpublished versions.
- Allowed CI and tag workflows to pass when the current package version is
  already present on npm, which is needed when a workflow is rerun after a
  successful local or automated publish.

## Verification

```powershell
npm run publish:check
npm view devflow-native version dist-tags --json
npx devflow-native@latest --version
```
